# 活动管理模块实现计划

## 一、模块概述

实现后台活动管理模块，包含活动列表管理和活动区Banner配置两大功能。

## 二、数据库设计

### 2.1 活动表 (core\_activity)

| 字段                | 类型            | 说明          |
| ----------------- | ------------- | ----------- |
| id                | bigint        | 活动ID（主键）    |
| activity\_name    | varchar(200)  | 活动名称        |
| poster\_url       | varchar(500)  | 活动海报URL     |
| organizer\_name   | varchar(100)  | 活动组织者名称     |
| organizer\_avatar | varchar(500)  | 活动组织者头像URL  |
| start\_time       | datetime      | 活动开始时间      |
| end\_time         | datetime      | 活动结束时间      |
| province          | varchar(50)   | 省份          |
| city              | varchar(50)   | 城市          |
| district          | varchar(50)   | 区县          |
| address           | varchar(500)  | 详细地址        |
| total\_capacity   | int           | 活动总人数       |
| registered\_count | int           | 已报名人数       |
| registration\_fee | decimal(10,2) | 活动报名费用      |
| activity\_detail  | longtext      | 活动详情（富文本）   |
| status            | char(1)       | 状态（0正常 1停用） |

### 2.2 活动报名用户表 (core\_activity\_registration)

| 字段                 | 类型            | 说明       |
| ------------------ | ------------- | -------- |
| id                 | bigint        | 报名ID（主键） |
| activity\_id       | bigint        | 活动ID     |
| user\_id           | bigint        | 用户ID     |
| user\_name         | varchar(100)  | 用户名称     |
| user\_avatar       | varchar(500)  | 用户头像     |
| phone              | varchar(20)   | 联系电话     |
| registration\_time | datetime      | 报名时间     |
| payment\_status    | char(1)       | 支付状态     |
| payment\_amount    | decimal(10,2) | 支付金额     |
| payment\_time      | datetime      | 支付时间     |

### 2.3 活动Banner表 (core\_activity\_banner)

| 字段           | 类型           | 说明           |
| ------------ | ------------ | ------------ |
| id           | bigint       | BannerID（主键） |
| banner\_name | varchar(200) | Banner名称     |
| image\_url   | varchar(500) | Banner图片URL  |
| activity\_id | bigint       | 关联活动ID       |
| sort\_order  | int          | 显示顺序         |
| status       | char(1)      | 状态（0正常 1停用）  |

## 三、后端实现步骤

### 3.1 实体类 (Domain)

* [ ] `CoreActivity.java` - 活动实体类

* [ ] `CoreActivityRegistration.java` - 活动报名用户实体类

* [ ] `CoreActivityBanner.java` - 活动Banner实体类

### 3.2 Mapper层

* [ ] `CoreActivityMapper.java` - 活动数据访问接口

* [ ] `CoreActivityMapper.xml` - 活动SQL映射文件

* [ ] `CoreActivityRegistrationMapper.java` - 报名用户数据访问接口

* [ ] `CoreActivityRegistrationMapper.xml` - 报名用户SQL映射文件

* [ ] `CoreActivityBannerMapper.java` - Banner数据访问接口

* [ ] `CoreActivityBannerMapper.xml` - Banner SQL映射文件

### 3.3 Service层

* [ ] `ICoreActivityService.java` - 活动服务接口

* [ ] `CoreActivityServiceImpl.java` - 活动服务实现

* [ ] `ICoreActivityRegistrationService.java` - 报名服务接口

* [ ] `CoreActivityRegistrationServiceImpl.java` - 报名服务实现

* [ ] `ICoreActivityBannerService.java` - Banner服务接口

* [ ] `CoreActivityBannerServiceImpl.java` - Banner服务实现

### 3.4 Controller层

* [ ] `CoreActivityController.java` - 活动管理接口

  * GET /core/activity/list - 获取活动列表

  * GET /core/activity/{id} - 获取活动详情

  * POST /core/activity - 新增活动

  * PUT /core/activity - 修改活动

  * DELETE /core/activity/{ids} - 删除活动

  * PUT /core/activity/changeStatus - 修改状态

  * GET /core/activity/registrations/{activityId} - 获取活动报名用户列表

* [ ] `CoreActivityBannerController.java` - Banner配置接口

  * GET /core/activityBanner/list - 获取Banner列表

  * GET /core/activityBanner/{id} - 获取Banner详情

  * POST /core/activityBanner - 新增Banner

  * PUT /core/activityBanner - 修改Banner

  * DELETE /core/activityBanner/{ids} - 删除Banner

  * PUT /core/activityBanner/changeStatus - 修改Banner状态

## 七、技术要点

* 使用MyBatis-Plus或原生MyBatis进行数据访问

* 富文本字段使用longtext类型存储HTML内容

* 省市选择采用级联方式，前端调用行政区划API

* Banner点击跳转使用activity\_id关联

* 分页查询使用BaseController的startPage()方法

* 权限控制使用@PreAuthorize注解

* 操作日志使用@Log注解
